# DSCI 552 Homework 3

This repository contains the completed notebook for the required portions of Homework 3 and the AReM data used by the notebook.

## Files

- `Wang_Gao_HW3.ipynb` - executed homework notebook
- `data/AReM/` - the 88 AReM activity recordings
- `requirements.txt` - Python dependencies

## Run

From the repository root:

```bash
python -m pip install -r requirements.txt
jupyter notebook Wang_Gao_HW3.ipynb
```

Run all notebook cells in order to reproduce the feature table and bootstrap confidence intervals.
